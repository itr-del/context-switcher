# 🔄 context-switcher

> 任务切换与上下文管理 Skill — 当用户说"切换任务/清空上下文/换话题/回到XX"时触发。

## ✨ 功能

- **任务状态保存**：切换前自动保存当前任务进度
- **上下文清理**：切换后清空不相关上下文，避免 Token 浪费
- **任务恢复**：可随时切换回历史任务
- **并行任务追踪**：支持多个任务并行切换

## 🎯 触发条件

- 用户说："切换任务"、"清空上下文"、"换话题"、"回到XX"
- 用户说："先做 A，然后做 B"
- 用户在多任务间穿梭
