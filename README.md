# 🔄 context-switcher

> 任务切换与上下文管理 Skill — 当用户说"切换任务/清空上下文/换话题/回到XX"时触发。

## ✨ 功能

- **任务状态保存**：切换前自动保存当前任务进度
- **上下文清理**：切换后清空不相关上下文，避免 Token 浪费
- **任务恢复**：可随时切换回历史任务
- **并行任务追踪**：支持多个任务并行切换

## 🎯 触发条件

- 用户说："切换任务"、"清空上下文"、"换话题"、"回到XX"
- 用户说："先做 A，然后做 B"
- 用户在多任务间穿梭

## 👤 关于这个项目的我

**我做这个的原因**：多任务并行时，上下文混在一起会让每次调用都在付"无关 Token"的费用，而且很容易把上一个任务的结论带进下一个任务。

**我负责的部分**：触发词识别、任务状态保存与恢复、上下文清理、并行任务追踪。

**技术选择的关键取舍**：用"显式触发词 + 状态快照"而不是自动判断——自动判断更聪明但不可控，会出现误清理；这个场景里**可预测比聪明更重要**。

**做完之后的收获**：做上下文管理的核心不是"记得多少"，是"什么时候该忘"。
